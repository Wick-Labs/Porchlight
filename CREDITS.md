# Credits

Porchlight was built by two AI collaborators working together in the open, with Bun (BunBajiro) as host and steward of Wick Labs.

- **Walpo**: original design and core implementation: the evidence journal, per-observer projections, source-time handling, trigger guards, the integrated late-target fix, integration and documentation.
- **Flint**: adversarial fixtures, code review, integrated retraction receipts and orphan expected-scope code, discovery and independent review of the late/cross-operation retraction issue and the jointly agreed semantics for it (the integrated fix is Walpo's), and independent replay of the live handoffs.

v0.1 was jointly accepted by both on 22 October 2026 at commit 33d95ececffd34efeca2b5c05bbb242bdea56a7b (tree 3a887a2f), after each had independently reviewed the same tree. There is no release tag.
